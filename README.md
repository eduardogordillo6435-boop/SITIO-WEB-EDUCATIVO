# Aprende Fácil — Sitio web educativo

Proyecto desarrollado con React + Vite para estudiantes de secundaria y bachillerato.

## Funcionalidades
- Inicio y navegación entre secciones.
- Materias: Matemáticas, Español, Ciencias e Inglés.
- Recursos de estudio con búsqueda, filtros y vista de detalle.
- Cuestionarios de cinco preguntas por materia, puntuación, explicación de respuestas y opción de volver a intentar.
- Secciones Nosotros y Contacto (formulario demostrativo, sin envío a servidor).
- Diseño adaptable a computadoras, tabletas y celulares.

## Requisitos
- Node.js 18 o superior.
- npm.

## Ejecutar en tu computadora
1. Descomprime el proyecto.
2. Abre la carpeta `aprende-facil` en Visual Studio Code.
3. Abre la terminal en esa carpeta.
4. Ejecuta:

```bash
npm install
npm run dev
```

5. Abre en el navegador la dirección local que indique Vite (normalmente `http://localhost:5173`).

## Generar versión de producción
```bash
npm run build
```

Los archivos listos para publicar se generan en la carpeta `dist`.

## Subir a GitHub
En la terminal, dentro de la carpeta del proyecto:

```bash
git init
git add .
git commit -m "Primera versión de Aprende Fácil en React"
git branch -M main
git remote add origin https://github.com/eduardogordillo6435-boop/SITIO-WEB-EDUCATIVO.git
git push -u origin main
```

Si ya clonaste el repositorio o ya tiene archivos, no ejecutes `git init` ni `git remote add origin` otra vez. Copia los archivos de este proyecto dentro de tu repositorio existente, revisa los cambios y ejecuta `git add .`, `git commit -m "Actualización del sitio Aprende Fácil"` y `git push`.

## Organización sugerida por Sprint
- Sprint 1: estructura React, navegación e inicio.
- Sprint 2: materias, recursos, filtros y detalle.
- Sprint 3: cuestionarios, respuestas y resultados.
- Sprint 4: Nosotros, Contacto y diseño responsive.
- Sprint 5: pruebas, correcciones, optimización y publicación.

> El contenido se guarda en archivos JavaScript locales. No incluye base de datos, registro de usuarios ni envío real del formulario.
